Read the full roleShow less

What you'll do

  • Design scalable backend architecture across both products.
  • Engineer systems for thousands of concurrent students.
  • Handle simultaneous assessments, classroom activities, and AI API requests.
  • Design caching, queues, databases, rate limiting, and request routing.
  • Manage cloud deployments, CI/CD, monitoring, security, and backups.
  • Define load-testing benchmarks and analyze results.
  • Identify and resolve performance bottlenecks.
  • Review high-traffic backend features built by the full-stack engineer.

  • Docker, CI/CD, monitoring, performance optimization, and security.
